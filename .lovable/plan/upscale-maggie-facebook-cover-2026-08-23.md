# Upscale Maggie Facebook Cover

## Goal
Refactor the existing Facebook cover into a polished, premium Magnolia Maids brand asset that preserves the exact Maggie avatar, prominently incorporates the real magnolia logo, and remains legible across Facebook desktop and mobile crops.

## Design direction
- Replace the small placeholder “M” medallion with the supplied magnolia flower mark as an intentional brand signature.
- Preserve Maggie’s face, illustration style, earrings, blazer, and lapel detail without AI reinterpretation.
- Simplify the message hierarchy so the cover reads instantly: brand, premium service promise, local service area, and website.
- Use the established ivory, laurel green, and restrained brass palette with editorial typography, subtle botanical texture, and more deliberate negative space.
- Keep the result upscale and neighborly rather than promotional or busy.

## Production
1. Rework the existing cover’s background and visual balance while retaining the strongest asymmetric portrait composition.
2. Rebuild the final layout at 1640×624 with the important logo, brand name, message, website, and Maggie’s face inside a center-safe crop.
3. Integrate the real magnolia logo at a useful visual scale, with contrast treatment that preserves its white petals and green leaves.
4. Export:
   - High-resolution Facebook cover: 1640×624
   - Standard Facebook cover: 820×312
5. Save the final downloadable files under `/mnt/documents/` as new versioned assets, preserving prior versions.

## Quality assurance
- Inspect the full-resolution cover and the standard-size export.
- Inspect a simulated center/mobile crop for face, logo, text, and URL safety.
- Check text edges, contrast, spacing, asset quality, and any visible cutout halos.
- Perform at least one refinement pass, then re-check all exports before delivery.

## Technical details
- Use the exact uploaded Maggie image and existing magnolia mark as source assets.
- Use deterministic canvas composition for precise typography, alignment, and crop control; image editing will be limited to background/refinement work so the supplied character and logo remain faithful.
- Apply the project’s existing brand tokens as the color reference and use premium local display/sans typography.
